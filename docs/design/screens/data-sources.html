Cài EA TradeLensSync

  1. Mở thư mục dữ liệu MT5 (File → Open Data Folder), copy TradeLensSync.mq5 vào MQL5/Experts và thư mục TradeLens vào MQL5/Include.
  2. Tools → Options → Expert Advisors → bật Allow WebRequest và thêm http://127.0.0.1:7878.
  3. Gắn EA vào một chart bất kỳ, dán token, bật Algo Trading. Deal mới sẽ hiện trong app sau khoảng 2 giây.

Script Python (MetaTrader5)

Lấy lại toàn bộ lịch sử từ terminal đang mở (chỉ Windows).

pip install MetaTrader5 python tradelens_sync.py --token a3f9…7c21 --days 365
